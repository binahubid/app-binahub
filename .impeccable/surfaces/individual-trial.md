# Individual paid-package demo

Mode: Operate. Extends the existing individual admin surface; not a redesign.

## Direction contract

- Purpose: let the CEO demonstrate package selection, clearly simulated checkout,
  actual full-bank completion, review and separate/combined scores before Mayar.
- World: inherit the admin app's navy/white, Jakarta Sans, 12px controls, restrained
  dividers. No new visual identity, decorative illustrations, glass or gradients.
- First viewport: a compact simulation notice and two selectable package rows,
  named PE/RM with the agreed prices and exact method counts.
- Interaction: selecting an answer updates immediately, Previous retains it;
  submission is the only server calculation. Review shows selected answers only.
- Mobile: single task column, wrapping step labels, optional instructions in details;
  report rows become labeled blocks, never a clipped desktop table.
- Boundary: verified admins only. No real payment, entitlement, emails, personal
  contact collection or production participant records. Browser-tab drafts expire
  after 24 hours and are not a production persistence guarantee.
- Scoring: actual private banks/server rules; 50:50 provisional module combined
  score; no invented RM SJT weighting per competency or validation claims.
